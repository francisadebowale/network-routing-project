# Network Routing Project

A networking project exploring routing, switching and Python automation using containerlab and FRRouting.

Tested features include static routing, BGP and OSPF loopback reachability, VLAN switching and inter-VLAN routing. A Python checker verifies expected BGP neighbour sessions and displays learned routes.

Planned features include IS-IS, ECMP, tunnelling and extended network monitoring. MPLS is deferred pending a compatible kernel.

See [topology and addressing](docs/topology.md) for the static routing, VLAN and OSPF networks.
